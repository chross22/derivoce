# The eastern Gulf of Maine box

Exposed so the region behind
[`eastern_gom_salinity()`](https://camilleross.org/derivoce/reference/eastern_gom_salinity.md)
can be inspected or plotted. Approximate, and not the exact footprint of
any published index.

## Usage

``` r
eastern_gom_box()
```

## Value

a named list with `xmin`, `xmax`, `ymin`, `ymax`

## Examples

``` r
eastern_gom_box()
#> $xmin
#> [1] -68
#> 
#> $xmax
#> [1] -66
#> 
#> $ymin
#> [1] 43
#> 
#> $ymax
#> [1] 44.5
#> 
```
