# Elapsed time between consecutive steps

Elapsed time between consecutive steps

## Usage

``` r
step_spacing(steps, per = "step")
```

## Arguments

- steps:

  a time-step table from
  [`time_steps()`](https://camilleross.org/derivoce/reference/time_steps.md)

- per:

  `"step"`, `"day"`, or `"month"`

## Value

numeric vector, one per step; the first is `NA`
