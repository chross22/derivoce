# Gradient magnitude and components of a single raster layer

Gradient magnitude and components of a single raster layer

## Usage

``` r
gradient_layers(layer, per = "km")
```

## Arguments

- layer:

  a one-layer `SpatRaster`

- per:

  distance unit, `"km"` or `"m"`

## Value

a three-layer `SpatRaster`: magnitude, eastward, northward
